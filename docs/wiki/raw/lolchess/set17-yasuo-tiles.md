# Set 17 야스오 칸 — 수치 정리

> 출처: lolchess.gg/rewards/set17/space-gods (2026-04-23 확인)
> 공식 인게임 텍스트 기준 — 기존 `set17-gods-system.md`의 추정 수치를 이걸로 대체.

## 개요

야스오(심연의 신)의 보상은 "**칸(tile)**"을 보드의 챔피언 위치에 설치하는 형태.
스테이지 2/3/4 각 신 선택 라운드(2-4/3-4/4-4)마다 **칸 1개**를 선택해 설치.

### 운용 규칙 (확정)
- **한 스테이지 = 칸 1개 선택**
- **칸은 영구** — 판이 끝날 때까지 보드에 유지됨 (라운드 단위 소모 아님)
- **누적됨** — 야스오를 2번 고르면 칸 2개, 3번 다 고르면 칸 3개가 동시에 보드에 존재
- **은총 트리거 (중요)**: **3회 신 선택(2-4/3-4/4-4)에서 전부 야스오를 골랐을 때만** 4-7 시점에 "야스오의 은총" 발동 → 설치된 **모든 칸 위력 +50%**. 2번만 고른 경우 은총 효과 없음(칸은 기본 위력 유지).
- 인게임 텍스트의 `[소모품]` 표기는 "칸 아이템을 사용하면 소멸(=보드에 설치되면 그 아이템은 사라짐)"의 의미로 해석됨. 설치된 **칸 자체는 영구**.

## 2 스테이지 (2-4)

선택 가능한 칸 **6종**:

| ID | 이름 | 효과 |
|----|------|------|
| `solar` | 태양 칸 | 칸에 있는 아군이 5초 동안 **+18% 마법 피해**를 입힘. 그 피해 지속시간 동안 **33% 상처** + **1% 화상** 적용 |
| `cryo` | 극저온 칸 | 칸에 있는 아군 체력이 처음으로 **40% 아래로 떨어지면** 1초 동안 얼어붙고 **최대 체력의 35% 회복** |
| `starlight` | 별빛 칸 | 칸에 있는 아군 **마나 재생 +3** |
| `accel` | 가속 칸 | 칸에 있는 아군 **공격 속도 +30%** |
| `storm` | 폭풍 칸 | 칸에 있는 아군이 처음으로 적에게 스킬을 적중시키면 **해당 적 2초 기절** |
| `cosmic` | 우주 칸 | 칸에 있는 아군이 **최대 체력 +10%**, **라운드마다 영구 체력 +30** |

## 3 스테이지 (3-4)

선택 가능한 칸 **5종** (우주 칸 제외) — 수치는 2 스테이지와 **완전 동일**:

- `solar`, `cryo`, `starlight`, `accel`, `storm`

## 4 스테이지 (4-4)

선택 가능한 칸 **5종** — 3 스테이지와 동일:

- `solar`, `cryo`, `starlight`, `accel`, `storm`

## 4-7 은총 — 야스오의 은총

- 야스오의 **칸 위력이 +50% 증가**
- 칸이 2개뿐이면 **12골드 추가 획득**
- (별도로 "황금 칸" 같은 신규 칸이 추가되는 건 아님 — 기존 칸들의 수치 배율 적용)

## 용어 주석

- **화상(burn)**: 매초 대상 최대 체력의 일정 비율만큼 고정 피해 (인게임 툴팁)
- **상처(wound)**: 체력 회복량 감소

## 시뮬레이터 관점 정리

### 데이터 표현
각 칸은 `YasuoTileEffect` 타입의 정규화된 레코드로 저장:

```ts
interface YasuoTileEffect {
  id: 'solar' | 'cryo' | 'starlight' | 'accel' | 'storm' | 'cosmic'
  name: string
  // 효과 파라미터 (수치)
  magicDamageAmp?: number        // 태양: 0.18
  magicDamageAmpDuration?: number // 태양: 5 (초)
  applyWound?: number            // 태양: 0.33 (상처 %)
  applyBurn?: number             // 태양: 0.01 (화상 %)
  lowHpTrigger?: number          // 극저온: 0.40 (체력 비율)
  lowHpFreezeDuration?: number   // 극저온: 1 (초)
  lowHpHeal?: number             // 극저온: 0.35 (최대 체력 비율)
  manaRegen?: number             // 별빛: 3
  attackSpeedBonus?: number      // 가속: 0.30
  stunOnFirstHit?: number        // 폭풍: 2 (초)
  maxHpBonusPct?: number         // 우주: 0.10
  permanentHpPerRound?: number   // 우주: 30
}
```

### 스테이지별 가용성
```ts
const YASUO_TILE_AVAILABILITY = {
  2: ['solar', 'cryo', 'starlight', 'accel', 'storm', 'cosmic'],
  3: ['solar', 'cryo', 'starlight', 'accel', 'storm'],
  4: ['solar', 'cryo', 'starlight', 'accel', 'storm'],
}
```

### 은총 보정
4-7 은총 획득 시 모든 활성 칸 효과 수치에 **×1.5 배율**을 적용.
(시뮬 엔진에서 은총 플래그를 읽어 곱 적용)

### 영구 + 자동 전파
- 칸은 설치 라운드 이후 **모든 PvP 라운드에 자동 복사**됨
- actual-data 툴에서는 shrine 라운드(2-4/3-4/4-4)에서 "이번 스테이지 칸 설치"를 기록하면, 직후 PvP 라운드부터 `hexModifiers[]`에 누적 포함하는 방식
- 설치 이후 유닛 재배치로 해당 헥스가 비어도 칸은 그 헥스에 남음 (다른 아군이 그 헥스로 오면 효과 받음)

### 은총 판정 — 수동 토글
- 자동 집계 계산 **없음**
- 양 팀(`playerTeam.graceApplied`, `opponent.graceApplied`) 각각 **사용자 수동 토글**
- 영상에서 상대 보드 칸이 강화된 시각 단서를 보고 사용자가 직접 체크
- 적용 시점은 4-7 이후(= 5-1 PvP 라운드부터) 모든 칸 효과에 **×1.5** 배율 적용
- 판정 근거 (사용자가 수동으로 판단할 기준): **3회 신 선택을 전부 야스오로** 골랐는지 여부
