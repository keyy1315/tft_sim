덱 추천 시 이론 DPS만 보지 말고 아래 제약 조건을 반드시 먼저 체크할 것.

**Why:** 데이터 수치만 보고 추천하면 매번 빗나감. 유저가 여러 번 지적함.

**How to apply:**

## 경제 현실
- 한 판 총 골드 ~200
- 3성 1개 = ~124골드 (3코 기준, 7렙 리롤)
- 3성 2개 동시 = ~174골드
- 3성은 핵심 1~2개가 현실적 한계
- 4코 이상 3성은 사실상 불가 (풀 10~9장, 다른 플레이어 공유)
- 5코 2성 여러 장 넣는 건 비현실적

## 아이템 슬롯
- 챔피언당 아이템 **최대 3개**
- **상징 아이템도 1슬롯 차지** → 상징 끼면 실제 아이템은 2개만
- "3템 + 상징" 불가능 → 반드시 2템 + 상징으로 계산

## 챔피언 역할 배분
- 후방 캐리에게 AS 중첩 아이템(구인수 등) → 안전하게 스택 쌓기
- 전방 브루저에게 흡혈+크리 → 맞으면서 회복하며 버티기
- 탱커 아이템은 **아군 캐리 유형**에 따라 다름:
  - AD 캐리 덱: 탱커는 오래 버티기 (정령의 형상, 덤불조끼)
  - AP 캐리 덱: 탱커가 마저 깎기 (이온 충격기)

## 아이템 선택 기준
- 스킬 캐리: 마나젠(쇼진/블루) + 크리(무대/보건) + 피해증폭(방파자)
- AA 캐리: AS 극대화(구인수+라위+레드) > AD/크리
- 물리 캐리 마나젠: 쇼진 > 푸파 (AD+15%가 AP 증폭보다 가치 있음)
- 타격대의 철퇴(방파자): 크리+피해증폭+AS+체력 만능템

## 시너지
- 같은 효과 티어면 수 늘려봤자 낭비 (5암흑 = 4암흑)
- 상징으로 시너지 올릴 때 최대 티어까지만
- 빈 시너지 슬롯은 다른 유용한 시너지로 채우기

## 덱 설계 접근법 (중요)
- **특정 시너지 하나에 꽂혀서 끼워맞추지 말 것**
- 먼저 **전체 시너지 목록을 훑고**, 2~3티어로 넓게 까는 것이 효율적
- 실제 메타 덱은 최대 티어 시너지가 거의 없고, 여러 시너지를 2~3티어씩 분산
  - 예: 진 캐리 — 저격수3 + 정령족3 + 요새2 + 암흑의 별2 + 전달자2
- 캐리 챔피언의 **모든 시너지**를 먼저 확인 (태고족처럼 놓치는 시너지 방지)
- 시너지 하나를 4~6으로 올리는 것보다 **2~3짜리 3~4개**가 팀 전체에 이득
