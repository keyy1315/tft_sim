# TFT 실시간 코치 앱 아이디어

## 컨셉

Overwolf 오버레이 앱으로 TFT 실시간 코칭. Claude가 데이터 분석/추천, 유저가 조작+상황 판단.

## 역할 분담

| 역할 | 담당 | 방식 |
|------|------|------|
| 상대 보드 확인 / 겹침 판단 | 유저 | 직접 보고 앱에 입력 or 음성 |
| 피벗 타이밍 제안 | 유저 | "지금 전환해야 할 것 같아" → AI가 전환 덱 추천 |
| 포지셔닝 | 유저 | 상대 암살자/블리츠 위치 대응 |
| 메타 덱 경로 추천 | AI | 현재 보드 기반 최적 덱 경로 |
| 리롤/레벨업 타이밍 | AI | 골드/레벨/확률 계산 |
| 아이템 조합 추천 | AI | 현재 재료 기반 최적 완성 아이템 |
| 증강 선택 비교 | AI | 3개 증강 승률/시너지 분석 |
| 경제 운영 | AI | 이자 관리, 골드 지출 최적화 |

## 기술 스택

- **Overwolf SDK**: TFT 게임 상태 실시간 읽기 (보드/상점/골드/레벨/체력)
- **Claude API**: 상황 분석 + 의사결정
- **시뮬레이터 데이터**: 챔피언/아이템/시너지 계산 로직 재사용
- **오버레이 UI**: HTML/CSS/JS (웹 기술)

## 필요 데이터

- lolchess.gg 메타 덱 승률/순방률
- 챔피언/아이템/시너지 통계
- 스테이지별 경제 패턴
- 리롤 확률 테이블 (이미 md에 저장됨)
- 증강별 승률 통계

## 개발 순서

1. 시뮬레이터 완성 (현재 진행 중)
2. 메타 데이터 수집/구조화
3. Overwolf 앱 프로토타입 (게임 상태 읽기 + 오버레이)
4. Claude API 연동 (상황 → 추천)
5. 유저 피드백 루프로 판단력 개선

## 목표

마스터 티어 도달

## 합법성

- 자동 입력(매크로/봇) 없음 → Riot 이용약관 위반 아님
- AI가 추천만 표시, 유저가 직접 조작
- Overwolf는 Riot 공식 파트너 → API 사용 합법
