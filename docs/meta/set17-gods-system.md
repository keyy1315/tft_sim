# Set 17 신들의 영역 시스템

> 패치 17.1 기준. 정확하지 않을 수 있음.

## 개요

기존 공동 선택(초밥) 라운드를 대체하는 Set 17 신규 시스템.
매 라운드 무작위 2명의 신 중 1명을 선택하여 보상 획득.

## 타이밍

| 라운드 | 내용 |
|--------|------|
| **2-4** | 신 선택 → 보상 (스테이지 2 보상) |
| **3-4** | 신 선택 → 보상 (스테이지 3 보상) |
| **4-4** | 신 선택 → 보상 (스테이지 4 보상) |
| **4-7** | 크립 라운드 종료 후 → **가장 많이 선택한 신의 은총 증강** 자동 적용 + 추가 보상(돈/조합 아이템) |

## 핵심 규칙

- **한 판에 신 2명이 무작위로 고정** — 3라운드 내내 같은 2명 중에서만 선택
- 다른 신은 그 판에서 선택 불가
- 은총도 해당 2명의 은총 중 하나만 가능
- 예: 아리/에코가 걸린 판 → 3번 다 아리 or 에코만 선택 → 은총도 아리 or 에코

## 4-7 은총 증강 결정

3번의 선택 중 가장 많이 고른 신의 은총이 자동 적용.
예: 아리 2회 + 에코 1회 → **아리의 은총** 증강 획득
