- lolchess.gg 통계를 기반으로 메타를 파악함
- 아이템 줄임말 사용 (방파자, 라위, 블루, 레드 등 — LoL 유래)
- 덱 추천 시 이론 DPS보다 실전 제약(경제, 슬롯, 타이밍)을 중시
- 잘못된 추천에 바로 피드백을 줌 — 피드백을 반영해야 함
- 시뮬레이터 개발자이면서 동시에 게임 유저
