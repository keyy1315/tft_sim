# Set 17 별돌보미 별자리

> 출처: lolchess.gg/synergies/set17/guide (2026-04-23 확인)
> 시너지 명: **별돌보미 (Stargazer)**
> (3) 시너지부터 활성. 매 게임 다른 별자리 1개가 무작위로 결정되어 고정.

## 공통 규칙
- 게임마다 **별자리 1개 고정** (무작위 결정, 게임 내 변경 불가)
- 강화된 칸 몇 개가 보드에 숨겨져 있고, **플레이어 레벨이 오를 때마다 추가 칸이 드러남**
- 별자리별 고유 효과는 강화된 칸에 있는 아군 및 별돌보미 유닛에게 적용

## 별자리 목록 (7종)

### 1. 제단 (Altar)
- (3) 챔피언이 사망하면 제단의 제물. 강화된 칸에 있는 아군 **체력 +8%, 공격 속도 +8%**
- 제물 60회 바치면 강화된 칸 별돌보미에 추가 AD +20%, AP +18% (색아이콘 누락 — 추정)

### 2. 멧돼지 (Boar)
- 플레이어 대상 전투 승리 후 골드 획득
- 강화된 칸 아군: 체력, 공격력, 주문력 +8% (별돌보미는 더 얻음)
- (3) 1골드, AD 2%, AP 10%
- (4) 2골드, AD 8%, AP 15%
- (5) 4골드, AD 15%, AP 25%
- (6) 6골드, AD 22%, AP 30%

### 3. 우물 (Well)
- 강화된 칸 아군 마나 재생 +1
- 별돌보미는 더 얻고 스킬로 체력 가장 낮은 아군 회복
- (3) 마나 재생 +1, 스킬 피해량의 18% 회복
- (5) 마나 재생 +5, 스킬 피해량의 25% 회복

### 4. 여사냥꾼 (Huntress)
- 전투 시작: 체력 가장 높은 적에게 표식
- 강화된 칸 아군 공속 +15%
- 강화된 칸 별돌보미: 능력치 더 + 표식 적 사망 시 최대 체력의 10% 회복
- (3) 공속 10%, 표식 3개
- (5) 공속 30%, 표식 5개
- (7) 공속 45%, 표식 7개

### 5. 메달 (Medal)
- (3) 강화된 칸 아군 피해 증폭 +12%. 아군 3성 유닛 하나당 +6.5% 증가

### 6. 산 (Mountain)
- 플레이어 대상 전투 5회마다 별돌보미 상징 획득
- 강화된 칸 별돌보미 다양한 추가 효과 (단계별 누적)
- (3) 체력 +12%
- (4) 또한 AD·AP +12%
- (5) 또한 방어력·마법 저항력 +12
- (6) 또한 공격 속도 +12%
- (7) 또한 내구력 +6%
- (8) 또한 그 외 모든 추가 효과 10% 증가
- (9~11): 정상·완주·모든 적 초대 (후반 대형 효과)

### 7. 뱀 (Snake)
- 강화된 칸 아군 내구력 +5%
- 강화된 칸 별돌보미: 능력치 더 + 적 중독 (입힌 피해 일부 3초에 걸쳐 마법 피해 재적용)
- (3) 내구력 5%, 중독 피해 25%
- (5) 내구력 10%, 중독 피해 40%
- (7) 내구력 15%, 중독 피해 60%

## 강화된 칸 (Enhanced Tile)

- 보드에 숨겨진 강화 헥스. 플레이어 레벨이 오를수록 드러나는 칸 수가 증가
- 정확한 레벨별 드러나는 개수는 페이지에서 확인 불가 — **실제 영상으로 확인 필요**
- actual-data에서는 각 PvP 라운드별 "현재 드러난 강화 칸 좌표 배열"을 기록

## 시뮬레이터 관점 정리

### 데이터 표현
```ts
type StargazerConstellationId =
  | 'altar' | 'boar' | 'well' | 'huntress' | 'medal' | 'mountain' | 'snake'

// 게임 레벨 (한 판 내 고정)
interface GameStargazerState {
  constellationId: StargazerConstellationId
}

// 팀 레벨 (라운드별 변함 — 레벨 오르면 새 칸 드러남)
interface TeamStargazerState {
  revealedTiles: HexCoord[]   // 현재 드러난 강화 칸 좌표
  // 별자리별 누적 카운터 (제단 제물 수, 산 다음 상징까지 남은 전투 등) — MVP 제외
}
```

### 기존 야스오 칸과의 차이
| 항목 | 야스오 칸 | 별돌보미 강화된 칸 |
|------|---------|----------------|
| 설치 시점 | shrine 라운드에서 선택 설치 | 게임 시작 시 무작위 배치, 레벨 따라 드러남 |
| 소유 | 설치한 플레이어 전용 | 플레이어 본인만 볼 수 있음(타인 무관) |
| 효과 | 칸에 있는 아군 전반 | 강화 칸에 있는 아군(특히 별돌보미) |
| 누적 | 최대 3개 | 별자리·레벨에 따라 달라짐 |
| 영구성 | 설치 후 영구 | 드러난 이후 영구 |

### 시뮬 엔진 관점
- MVP에서는 **시뮬 엔진 구현 미포함** — actual-data 툴에서 기록만
- Phase 3 시뮬 검증 단계에서 별돌보미 별자리별 효과 구현 (8명 × 중첩 × 조건부 누적 로직 필요, 복잡도 큼)

## 미확인 사항

- 각 별자리마다 **아이콘이 붙은 스탯**(예: "20% ?") 정확한 스탯 종류 (AD? AP? AS?) — 색 있는 텍스트는 HTML 파싱에서 누락. 실제 게임 내 툴팁 확인 필요
- 별자리 **8번째** 존재 여부 (일반적으로 Set 별자리는 8~9종, 현재 7종만 확인)
- 플레이어 레벨별 드러나는 강화 칸 개수 정확한 규칙
