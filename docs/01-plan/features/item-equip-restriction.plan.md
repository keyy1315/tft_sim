## 1. 현재 상태 분석

### 1.1 문제점

현재 `addChampionItem`(`teamSlice.ts:63-69`)에서 아이템 장착 시 유일한 제한은 **최대 3개**뿐이다.
168개 전체 아이템(조합재료 10 + 완성템 49 + 유물 36 + 필트오버 20 + 빌지워터 34 + 특수 1)을 아무 챔피언에게나 자유롭게 장착할 수 있다.

### 1.2 실제 게임 규칙과의 차이

| 아이템 카테고리 | 실제 게임 규칙 | 현재 구현 |
|---------------|-------------|---------|
| **조합재료** (10) | 챔피언에 장착 가능, 2개 합쳐서 완성템 생성 | ✅ 장착 가능 (조합 미구현) |
| **완성템** (49) | 챔피언에 자유 장착 (최대 3개) | ✅ 장착 가능 |
| **유물** (36) | 챔피언 1개당 유물 1개만, 완성템 슬롯 공유 | ❌ 제한 없음 |
| **필트오버** (20) | 시너지 2/4/6 활성 시 각 단계당 모듈 1개 선택, 8초 후 발동 | ❌ 시너지 무관하게 자유 장착 |
| **빌지워터** (34) | 시너지 3/5/7/10 활성 시 뱀화폐로 구매, 별도 슬롯 | ❌ 시너지 무관하게 자유 장착 |
| **특수** (1: 공간 왜곡) | 특정 조건에서만 획득 | ❌ 자유 장착 |

## 2. 구현 범위

### 2.1 핵심 구현 (Must Have)

#### R1: 아이템 카테고리별 장착 가능 여부 판별 함수

`src/lib/simulator/systems/item.ts`에 장착 가능 여부를 반환하는 검증 함수를 추가한다.

```
canEquipItem(item, champion, team, activeTraits) → { canEquip: boolean, reason?: string }
```

**규칙:**
- **조합재료**: 장착 가능 (MVP에서 조합 시스템은 미구현, 단순 스탯 부여)
- **완성템**: 장착 가능 (기존과 동일)
- **유물**: 해당 챔피언이 이미 유물을 보유하고 있으면 장착 불가
- **필트오버 모듈**: 필트오버 시너지 활성 단계에 따라 선택 가능 개수 제한
- **빌지워터 아이템**: 빌지워터 시너지 활성 시에만 장착 가능
- **특수 아이템**: 장착 불가 (비전투 아이템)

#### R2: 필트오버 모듈 시스템

- 필트오버 시너지 활성 단계: 2/4/6 → 각 단계당 모듈 **1개** 선택 가능
  - 2 필트오버: 모듈 1개
  - 4 필트오버: 모듈 2개
  - 6 필트오버: 모듈 3개
- 모듈은 **팀 전체**에서 공유 (특정 챔피언 장착이 아님)
- 전투 시작 8초(`InventionFireTime`) 후 해당 모듈 효과 발동
- `PlacedChampion.items`가 아닌 별도 상태로 관리

#### R3: 빌지워터 아이템 시스템

- 빌지워터 시너지 활성 시 뱀(Serpent) 화폐 기반 상점 시스템
  - 3 빌지워터: 라운드당 뱀 15개, 처치당 1개
  - 5 빌지워터: 라운드당 뱀 35개
  - 7 빌지워터: 라운드당 뱀 65개
  - 10 빌지워터: 라운드당 뱀 150개
- 빌지워터 아이템은 **스탯 티어 아이템**(ArmorMR/AS/ADAP/AP/AD/Health Tier 1-3)과 **고유 아이템**(단검, 해적검 등)으로 분류
- 시뮬레이터 특성상 뱀 화폐 경제는 생략하고, **시너지 활성 여부만 체크**하여 장착 허용

#### R4: UI 반영 — ItemGrid 필터링

- `ItemGrid.tsx`에서 카테고리를 세분화: `component | combined | artifact | piltover | bilgewater`
- 장착 불가 아이템은 **회색 비활성화** 처리 + 호버 시 사유 툴팁 표시
- 현재 활성 시너지 정보를 받아서 필트오버/빌지워터 탭의 활성화 여부를 결정

#### R5: Store 레벨 검증

- `teamSlice.ts`의 `addChampionItem`에서 `canEquipItem` 호출
- 검증 실패 시 상태 변경 없이 반환

### 2.2 범위 외 (Out of Scope)

- 아이템 조합 시스템 (조합재료 2개 → 완성템)
- 뱀 화폐 경제 시뮬레이션 (라운드별 수입/지출)
- 필트오버 모듈 전투 중 8초 지연 발동 (엔진 이벤트 시스템 필요 — 별도 feature로)
- 빌지워터 상점 UI (구매/판매 인터랙션)
- 아이템 중복 장착 규칙 (유니크 아이템 등)

## 4. 구현 순서

1. **타입 정의** — `ItemCategory` union type, 검증 결과 타입 추가
2. **검증 로직** — `item.ts`에 `canEquipItem` 함수 구현
3. **Store 연동** — `teamSlice.ts`에서 장착 시 검증 호출
4. **UI 반영** — `ItemGrid.tsx` 카테고리 세분화 + 비활성화
5. **필트오버 모듈 상태** — 별도 슬라이스 또는 teamSlice 확장
6. **빌드 검증** — `pnpm lint && pnpm typecheck && pnpm build`
