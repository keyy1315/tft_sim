## 1. 현재 문제점 (390x844 iPhone 기준)

- 3컬럼 레이아웃(시너지 | 보드 | 챔피언풀)이 가로로 넘침
- 보드 SVG가 잘림 (가로 700px+ → 390px 뷰포트)
- 시너지 패널과 챔피언 풀이 겹침
- 드래그앤드롭이 터치에서 작동하지만 UX가 불편
- 버튼/텍스트가 너무 작음

---

## 2. 모바일 레이아웃 설계

### 2.1 세로 스택 구조

```
┌──────────────────────┐
│ 헤더 (축소)           │
│ [전투 시작] [팀 코드]  │
├──────────────────────┤
│ ▶ 시너지 (접기/펼치기) │  ← 아코디언
├──────────────────────┤
│                      │
│   보드 (축소/스크롤)   │  ← 가로 스크롤 또는 축소
│                      │
├──────────────────────┤
│ 선택된 유닛 편집 카드   │  ← 더블터치 시 표시
│ [★] [★★] [★★★]      │
│ 아이템: [+] [+] [+]  │
├──────────────────────┤
│ [챔피언] [아이템] 탭   │  ← 하단 고정
│ 🔍 검색...            │
│ [챔피언 그리드 4열]    │
└──────────────────────┘
```

### 2.2 브레이크포인트

| 화면 | 너비 | 레이아웃 |
|------|------|---------|
| 데스크톱 | >= 1024px | 현재 3컬럼 유지 |
| 태블릿 | 768~1023px | 2컬럼 (보드+시너지 | 챔피언풀) |
| 모바일 | < 768px | 세로 스택 |

## 3. 컴포넌트별 변경사항

### 3.1 `page.tsx` — 메인 레이아웃

**데스크톱 (현재 유지):**
```
flex gap-3 → [시너지 w-52] [보드 flex-1] [챔피언풀 w-64]
```

**모바일:**
```
flex flex-col → [헤더] [시너지 아코디언] [보드] [유닛 편집] [챔피언/아이템 풀]
```

- `useMediaQuery` 또는 Tailwind `lg:` 프리픽스로 분기
- 모바일에서 시너지 패널은 **아코디언** (기본 접힘, 탭하면 펼침)
- 증강 슬롯은 모바일에서 보드 아래에 한 줄로 배치

### 3.2 보드 (`SetupBoard.tsx`)

- 모바일에서 `HEX_R` 축소 (44 → 28~32) 또는 `transform: scale(0.6)`
- 가로 스크롤 허용 (`overflow-x: auto`)
- 셀 좌표 텍스트 숨김 (모바일에서 불필요)

### 3.3 인터랙션

| 동작 | 데스크톱 | 모바일 |
|------|---------|--------|
| 챔피언 배치 | 셀 클릭 → 모달 | 셀 터치 → 모달 (동일) |
| 유닛 선택 | 더블클릭 | 더블터치 |
| 유닛 편집 | 좌측 패널에 표시 | 보드 아래 카드로 표시 |
| 아이템 장착 | 우측 패널 드래그 | 유닛 편집 카드에서 [+] 터치 → 모달 |
| 유닛 이동 | 드래그앤드롭 | 드래그앤드롭 (dnd-kit 터치 지원) |
| 유닛 제거 | 우클릭 | 편집 카드에서 [제거] 버튼 |
| 별 변경 | 클릭 사이클 | 편집 카드에서 [★] 버튼 |

### 3.4 챔피언/아이템 풀 (하단)

- 모바일에서는 **하단 고정** (sticky bottom)
- 높이 제한 (max-h-[40vh]) + 스크롤
- 챔피언 그리드: 5열 → 4열
- 아이템 그리드: 6열 → 5열
- 검색바 유지

### 3.5 헤더/네비게이션

- 모바일에서 "TFT Set 16 시뮬레이터" → "TFT S16"으로 축소
- 네비 링크는 햄버거 메뉴 또는 아이콘으로 축소

### 3.6 리플레이 모드 (모바일)

```
┌──────────────────────┐
│ TEAM A 승리!          │
├──────────────────────┤
│ [⏮] [▶] [⏭] x2     │
│ ═══ 시크바 ═══       │
├──────────────────────┤
│                      │
│   ReplayBoard (축소)  │
│                      │
├──────────────────────┤
│ 이벤트 로그           │
│ 데미지 테이블          │
│ [설정으로 돌아가기]    │
└──────────────────────┘
```

## 5. 구현 순서

1. **Tailwind 반응형 분기** — `page.tsx`에서 `flex-col lg:flex-row` 적용
2. **시너지 패널 아코디언** — 모바일에서 접기/펼치기
3. **보드 축소** — 모바일에서 scale 또는 HEX_R 축소
4. **유닛 편집 카드** — 보드 아래 전폭 카드로 표시
5. **하단 챔피언/아이템 풀** — 모바일 하단 고정
6. **헤더 축소** — 모바일 네비게이션 간소화
7. **리플레이 모드** — 모바일 세로 스택
8. **터치 테스트** — Playwright 모바일 뷰포트 검증

## 6. 참고사항

- dnd-kit은 터치 이벤트 기본 지원 (PointerSensor)
- 팀 코드 복붙이 모바일 메인 사용 시나리오
- 증강 선택은 모달이라 모바일에서도 작동
- 모바일에서 100회 시뮬 버튼은 유지 (결과만 보기)
