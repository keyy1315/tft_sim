## Executive Summary

| 항목 | 내용 |
|------|------|
| Feature | 챔피언 스킬 특수 효과 |
| 작성일 | 2026-03-23 |
| 상태 | Plan |

| 관점 | 내용 |
|------|------|
| **Problem** | 현재 어빌리티 시전 시 데미지+보호막만 처리. CC(기절/둔화), 스탯 버프, 체력 회복, 패시브, 방어력 감소 등 대부분의 특수 효과가 누락되어 전투 결과가 실제 게임과 크게 다름 |

## 1. 현재 상태

어빌리티 시전 시 처리되는 것:
- 대쉬 이동 (config.dash)
- 보호막 (getAbilityShield)
- 데미지 (findAbilityTargets → 다중 타겟 루프)
- 옴니뱀프 회복

**누락**: CC, 스탯 버프/디버프, 체력 회복, 패시브, 특수 메커닉

## 3. 구현 설계 방향

### 3.1 AbilityConfig 확장

```typescript
export interface AbilityConfig {
  pattern: AbilityPattern;
  radius?: number;
  maxTargets?: number;
  damageDecay?: number;
  dash?: 'to_target' | 'to_farthest' | 'to_lowest_hp' | 'to_backline';
  // 새로 추가
  stun?: number;           // 기절 지속시간 (초)
  stunTargets?: number;    // 기절 대상 수 (기본: 데미지 대상 전원)
  heal?: boolean;          // 시전자 체력 회복 여부
  selfBuff?: {             // 자기 버프
    attackSpeed?: number;  // 공속 증가 비율
    duration?: number;     // 지속시간 (초)
    ad?: number;           // 공격력 증가
    durability?: number;   // 내구력(피해 감소) 증가
  };
  allyBuff?: {             // 아군 버프
    attackSpeed?: number;
    duration?: number;
  };
  debuff?: {               // 적 디버프
    armorReduction?: number;  // 방어력 감소
    mrReduction?: number;     // 마저 감소
    duration?: number;
  };
}
```

### 3.2 combatLoop.ts 어빌리티 시전부 확장

현재: 데미지 → 보호막 → 사망 체크
확장: 데미지 → **CC 적용** → **디버프 적용** → 보호막 → **회복** → **버프** → 사망 체크

## 5. 수용 기준

1. Phase 1 (CC): 스킬에 기절 효과가 있는 챔피언이 시전 시 대상에 stun 적용
2. Phase 2 (버프): 자기 강화 스킬이 시전 시 공속/공격력 등 실제 증가
3. Phase 3 (회복): 회복 스킬이 시전 시 체력 실제 회복
4. Phase 4 (디버프): 방어력/마저 감소가 대상에 실제 적용
5. 전투 로그에 각 효과가 기록됨
6. `pnpm lint && pnpm typecheck && pnpm build` 통과
