## 1. 현재 상태 분석

### 1.1 현재 전투 흐름 (문제점)

```
[전투 시작] 클릭
  → simulateCombat() 실행 (즉시 완료)
  → setViewMode('replay') → 리플레이 모드 전환
  → 수동으로 ▶ 버튼 클릭해야 재생 시작
```

**문제점:**
1. 전투 시작하면 **바로 결과가 나와버림** → 스포일러
2. 리플레이를 **수동으로 재생** 버튼 눌러야 함 → 한 스텝 더 필요
3. setup 모드와 replay 모드가 **완전히 전환**됨 → 편집하면서 비교 불가
4. 전투 보드가 너무 작고, 유닛 구분이 어려움

### 1.2 현재 리플레이 모드 UI 구조

```
┌─────────────────────────────────┐
│ 승리 배너 (TEAM A 승리!)         │  ← 전투 시작하자마자 결과가 보임
├─────────────────────────────────┤
│ 재생 컨트롤 (⏮ ▶ ⏭ x1 x2 x4) │
├───────────────────┬─────────────┤
│                   │ 유닛 상세    │
│   ReplayBoard     │ 유닛 목록    │
│   (SVG hex grid)  │             │
├───────────────────┴─────────────┤
│ 이벤트 로그                      │
│ 전투 로그 (필터: 공격/스킬/사망)  │
└─────────────────────────────────┘
```

## 2. 변경 사항

### 2.1 R1: 전투 시작 → 즉시 자동 재생

**현재:** 전투 시작 → 결과 표시 → 수동 재생
**변경:** 전투 시작 → **자동 재생 시작** → 전투 종료 후 결과 표시

```typescript
// runSimulation 함수 수정
const result = simulateCombat(...);
setCombatResult(result);
setViewMode('replay');
setReplayTick(0);
setIsPlaying(true);    // ← 자동 재생 시작!
setIsRunning(false);
```

### 2.2 R2: 결과 표시 타이밍 변경

- 전투 중: 상단에 **"전투 진행 중... {시간}초"** 표시
- 전투 종료(마지막 틱 도달): **결과 배너 페이드인**
- 100회 시뮬 결과는 별도 모달 또는 즉시 표시 (자동 재생 없음)

### 2.3 R3: 전투 UI 리디자인 제안

#### 제안 A: 보드 중심 확대 + 사이드 패널 축소

```
┌──────────────────────────────────────────┐
│ 전투 진행 중... 3.2초  |  ⏮ ⏸ ⏭ x2    │  ← 컴팩트 컨트롤 바
├──────────────────────┬───────────────────┤
│                      │ TEAM A   TEAM B   │
│                      │ ♥ 2450   ♥ 1820  │  ← 팀 HP 합계
│    ReplayBoard       │                   │
│    (확대, 유닛 크게)   │ 데미지 차트        │  ← 실시간 DPS
│                      │ (막대 그래프)       │
│                      │                   │
│                      │ 킬 피드            │  ← 최근 이벤트
├──────────────────────┴───────────────────┤
│ ════════════ 시크바 ═══════════════      │
└──────────────────────────────────────────┘
```

**핵심 변경점:**
1. **보드 크기 확대** — HEX_R 32→44, 유닛 이미지 더 크게
2. **팀 총 HP 실시간 표시** — 우측 상단에 양 팀 HP 합계 바
3. **실시간 데미지 차트** — 우측에 유닛별 누적 데미지 막대 그래프
4. **킬 피드** — 사망/스킬 이벤트만 짧게 우측 하단에 표시
5. **시크바를 하단으로** — 전체 폭 사용

#### 제안 B: 풀스크린 보드 + 오버레이

```
┌──────────────────────────────────────────┐
│ [3.2s] ⏮ ⏸ ⏭ x2          TEAM A 승리! │  ← 투명 오버레이
│                                          │
│              ReplayBoard                 │
│              (풀 스크린)                   │
│                                          │
│  TEAM A ♥████░░ 2450                     │  ← 왼쪽 HP 오버레이
│  TEAM B ♥██░░░░ 1820                     │
│                                          │
│ ════════════ 시크바 ═══════════════      │
│ [접기] 데미지 테이블 / 이벤트 로그        │  ← 토글 가능
└──────────────────────────────────────────┘
```

#### 제안 C (권장): 분할 뷰 — 편집 + 전투 동시

```
┌──────────────┬───────────────────────────┐
│ 편집 패널     │ 전투 뷰                    │
│ (시너지,     │ [3.2s] ⏸ x2   전투 진행 중 │
│  아이템,     │                            │
│  유닛 선택)  │    ReplayBoard             │
│              │    (큰 보드)                │
│              │                            │
│              │ A: ♥████ 2450  B: ♥██ 1820 │
│              │ ═══ 시크바 ═══             │
│              ├────────────────────────────┤
│              │ 데미지 테이블               │
└──────────────┴───────────────────────────┘
```

- 왼쪽: 기존 편집 패널(시너지, 아이템) 축소 유지
- 오른쪽: 전투 보드 + 컨트롤 + 결과
- "설정으로 돌아가기" 버튼 불필요 — 동시에 보임

## 3. 유닛 비주얼 개선

### 3.1 현재 문제점

- 유닛 아이콘이 작아서 챔피언 구분 어려움 (HEX_R=32)
- HP/마나 바가 너무 얇아서 안 보임
- 팀 구분이 약함 (얇은 ring만)
- 상태 이상이 작은 글씨로 표시

### 3.2 개선안

| 요소 | 현재 | 개선 |
|------|------|------|
| HEX_R | 32 | 40~44 |
| HP 바 높이 | 3~5px | 6~8px |
| 마나 바 | 3px, 잘 안 보임 | 4px + 파란색 글로우 |
| 팀 구분 | 얇은 ring | **두꺼운 테두리** (파랑/빨강 3px) |
| 사망 유닛 | grayscale | grayscale + **X 마크** + 투명도 0.3 |
| 공격 애니메이션 | 직선 | **점선 화살표** + 데미지 숫자 강조 |
| 스킬 이펙트 | 보라색 점선 | **글로우 이펙트** + 범위 표시 |

## 4. 구현 순서

1. `runSimulation`에 `setIsPlaying(true)` 추가 (즉시 자동 재생)
2. 결과 배너를 마지막 틱 도달 시에만 표시하도록 조건 변경
3. ReplayBoard HEX_R 확대 + HP/마나 바 개선
4. 팀 HP 합계 실시간 표시 컴포넌트 추가
5. 전투 컨트롤 바를 컴팩트하게 리디자인
6. (선택) 분할 뷰 레이아웃 적용
