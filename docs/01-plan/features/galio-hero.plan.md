## 1. 현재 참고 구현 — 녹서스 아타칸

`combatLoop.ts`에 이미 녹서스 아타칸 소환 패턴이 있음:
- 녹서스 시너지 활성 + 별레벨 합 조건 충족 시 전투 중 소환
- `spawnNoxusAtakhan()` 함수로 CombatUnit 동적 생성
- 소환 시 전투 로그 기록

갈리오도 동일 패턴으로 구현 가능.

---

## 2. 구현 범위

### 2.1 갈리오 소환 조건

- **데마시아 시너지** (`TFT16_Demacia`) 활성화 (activeEffect 존재)
- **갈리오가 대기석에 있음** → `SimulateOptions`에 갈리오 정보 전달 필요
- **소환 시점**: 전투 시작 8초 후 (InventionFireTime과 유사) 또는 데마시아 시너지 변수에서 읽음

### 2.2 착지 효과

JSON 데이터 기준:
- **범위**: 3칸 (`HexRadius: 3`)
- **데미지**: 적 최대 체력 10% 마법 피해 (`PercentMaxHP: 0.10`)
- **CC**: 기절 1초 (`KnockupDuration: 1`) — 중심 거리에 따라 감소

### 2.3 갈리오 유닛 스킬

소환 후 갈리오는 일반 유닛처럼 전투 참여:
- **패시브**: 기본 공격 3회마다 대상 주변 범위 마법 피해 (마저 비례)
- **스킬**: 적 무리로 돌진 + 아군 보호막 (2칸, 4초) + 적 범위 피해 (마저+방어력 비례)

### 2.4 UI 변경

- 갈리오를 전장에 드래그하면 경고 표시 ("갈리오는 대기석에만 배치 가능")
- 또는 별도 "대기석 갈리오" 슬롯 추가
- 간단한 방법: `SimulateOptions`에 `playerBenchGalio` / `enemyBenchGalio` 필드 추가

## 5. 수용 기준

1. 데마시아 시너지 활성 + 갈리오 대기석 보유 시 전투 중 갈리오 소환
2. 착지 시 3칸 범위 적에게 최대 체력 10% 마법 피해 + 1초 기절
3. 소환 후 일반 유닛으로 전투 참여
4. 전투 로그에 소환/착지 이벤트 기록
5. 갈리오를 전장에 직접 배치하면 경고 또는 자동으로 대기석 처리
6. `pnpm lint && pnpm typecheck && pnpm build` 통과
